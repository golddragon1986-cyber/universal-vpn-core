# Universal VPN Core

Контейнер VPN для MikroTik RouterOS на ARMv7 и ARM64.

Панель управляет VPN-профилями, подписками, маршрутами, DNS и компонентами. В сборке 0.31b добавлены вкладка «Клиенты», просмотр локальных DNS-записей RouterOS, настройка ручных маршрутов, сохранение счётчиков трафика и проверка обновлений панели из GitHub. [Список изменений](version/0.31b.191126.1600/universal-vpn/CHANGELOG.md).

Образы содержат пять начальных правил RB4011 и соответствующие наборы GeoDAT. Пользовательских VPN-профилей, подписок и закрытых настроек в образах нет. Настройка маршрутизации и DNS выполняется установщиком и панелью для конкретного роутера.

## Установка последнего релиза из GitHub

На роутере должны быть установлены пакет RouterOS `container` и включён `device-mode container`. Сохраните резервную копию RouterOS. Затем выполните в его терминале:

```routeros
/tool fetch url="https://github.com/golddragon1986-cyber/universal-vpn-core/releases/latest/download/install-latest.rsc" dst-path="install-latest.rsc" check-certificate=yes http-max-redirect-count=5
/import file-name="install-latest.rsc"
```

Ссылка остаётся одной и той же для следующих релизов. Скрипт скачает образ для архитектуры роутера и четыре установочных скрипта из текущего выпуска. Он выведет путь к файлам и команды для проверки и запуска `01-install.rsc`. Прочитайте [полную инструкцию текущего релиза](version/0.31b.191126.1600/universal-vpn/README.md) до запуска установки.

Скрипт проверяет HTTPS-сертификат при загрузке. RouterOS не сверяет SHA-256 скачанного образа; [контрольные суммы 0.31b](version/0.31b.191126.1600/universal-vpn/SHA256SUMS) можно проверить на компьютере. Установщик рассчитан на новый экземпляр и останавливается при конфликте с существующим контейнером.

## Обновление панели

Панель проверяет [манифест обновлений](https://raw.githubusercontent.com/golddragon1986-cyber/universal-vpn-core/main/updates/panel/stable.json), скачивает `panel.tar.gz`, сверяет размер и SHA-256, сохраняет предыдущий код и может откатить неудачное обновление. Рабочие настройки и VPN-профили в этот архив не входят.

Начиная со следующего выпуска, архив панели будет прикрепляться к тому же релизу, что и контейнер. Для совместимости с уже выпущенным образом 0.31b служебный архив панели 0.3.1 остаётся доступным по прежней ссылке.

## Состав репозитория

- `vendor/panel/panel` — исходники панели.
- `scripts` — сборка и установка.
- `updates/panel` — версия и манифест обновления панели.
- `version/0.31b.191126.1600/universal-vpn` — документы и установочные скрипты текущего выпуска.

Образы ARMv7 и ARM64 скачиваются из [GitHub Releases](https://github.com/golddragon1986-cyber/universal-vpn-core/releases/latest). Испытание загрузки образа ARM64 на реальном устройстве в документации 0.31b не заявлено.
