# ac³: Speedtest.net Stockholm и отключение swap

Portable speedtest-go 1.8.3 (сторонний клиент сети Speedtest.net) запущен на Windows-компьютере, не установлен на роутер. HTTP proxy 192.168.99.1:11080, сервер RETN Stockholm №32926, --thread=8, HTTP transport, ping-mode=http. Фактический адрес сервера из метаданных клиента: https://server-32926.prod.hosts.ooklaserver.net:8080/speedtest/upload.php. На время проверки только этот домен принудительно направлен через CHANNEL-SV-inbound. API показал HTTPS-цепочки SV-inbound / CHANNEL-SV-inbound. FL не включался.

Результат проверенного запуска: download 6 243 030,479 байт/с = 49,94 Мбит/с; upload 4 247 371,483 байт/с = 33,98 Мбит/с; HTTP latency 136,07 мс, jitter 2,82 мс. Максимальная общая CPU в кратких снимках 81%. Это не непрерывный профиль. Значения задержки относятся ко всему пути через прокси и VPN, не прямому маршруту провайдера. Клиент ограничивает число потоков параметром 8; алгоритм отдачи адаптивный.

Предыдущие Cityhost Stockholm №69743 на 8/16 потоках вернули dl_speed=-1 и ul_speed=-1; это невалидные замеры, их скорости не учитывались. Первый RETN запуск не прошёл проверку маршрута из-за смены адреса сервером Speedtest и также исключён. Успешный RETN запуск повторён с точным доменом. Постоянная конфигурация восстановлена.

## USB и swap

В подтверждённом RETN запуске sda: sectors_read 9 486 734 → 9 491 926, sectors_written 3 681 616 → 3 682 024. Сектор 512 байт: прочитано 2 658 304 байт, записано 208 896 байт (204 КиБ). Disk io_ms 899 790 → 900 640 (850 мс совокупно за запуск). memory.swap.current не изменился: 5 914 624 байта. Это не признаки ограничения пропускной способности записью на USB. Отдельный тест максимальной скорости USB не выполнялся.

После теста по просьбе пользователя выполнено:

```
/disk set [find where slot="file-usb1-part1-swapfile"] swap=no
```

Настройка RouterOS сохранена постоянно; swap-файл не удалялся. Проверено: swap=no, /proc/swaps пустой, Swap total/used=0, memory.swap.current=0. Свободная память RouterOS 70 МиБ; MemAvailable контейнерного /proc/meminfo около 102 МиБ. OOM/OOM kill/max/high = 0. Панель HTTP 200. Контейнер перезапускать не потребовалось.

Сырые данные успешного теста: build/hap-ac3-clean/stockholm-retn-speedtest.json.
