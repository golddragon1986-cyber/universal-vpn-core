# hAP ac3: проверка переноса REALITY/ML-KEM в Xray

Xray на устройстве: 26.10.31, linux/arm, go1.27.3.

Обнаружены два отдельных ограничения конвертера:

1. Безусловный запрет флага support-x25519mlkem768 для Xray.
2. Временный файл `xray run -test` не имел расширения, поэтому ядро не могло
   определить формат. Для Xray временные конфиги теперь имеют suffix .json.

## Реальные сетевые тесты

Изолированные процессы Xray, порты 127.0.0.1:18751/18752. Рабочие profiles
в панели на время тестов не переключались. Native REALITY show использовался
только в изолированном конфиге для подтверждения фактически согласованного
X25519MLKEM768; сырой debug-log не экспортируется из контейнера.

- Randomized: 2 запуска, оба подключения отклонены, ML-KEM в наблюдавшихся
  согласованиях false. Допускать такой перенос только по номеру версии нельзя.
- Chrome / gstatic: FL 6/6 HTTP 204, SV 4/6 HTTP 204, два таймаута.
- Chrome / Cloudflare: FL 6/6 HTTP 204, SV 0/6 (таймауты).
- У успешных Chrome handshake native Xray подтвердил ML-KEM=true.
- Во время параллельных тестов увеличивался memory.events high (мягкий reclaim),
  но max/oom/oom_kill не увеличились. Это не доказывает причину таймаутов SV.

Таким образом, FL совместим с проверенным Chrome/ML-KEM путём. Для SV
полная работоспособность Xray не подтверждена; он оставлен на sing-box.

## Установленное поведение

- ML-KEM допускается для Xray 26.10.31+ с проверенным Chrome TLS-профилем.
- При переносе исходного randomized/randomizednoalpn для REALITY/ML-KEM
  Xray получает Chrome; исходный профиль хранится без изменения для возврата.
- Панель явно сообщает об этом engine-specific выборе при успешной смене.
- Остальные неподтверждённые fingerprint и старые версии сохраняют отказ.
- Встроенная проверка соединения и откат при неудаче не отключены.
- Установлены локальный исходник, runtime и package-копия hAP.
- 13 unit-тестов прошли на ARM устройства.
- Рабочий выбор обоих VPN и балансировки сохраняется на sing-box.

Резерв конвертера на устройстве: vpn_clients.py.before-xray-mlkem-fix.
Сценарии: test-hap-xray-isolated.py, install-xray-converter-fix.py.
