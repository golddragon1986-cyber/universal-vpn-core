# Рабочая конфигурация sing-box на RB4011

4 ноября 2026. Контейнер `universal-vpn-core`, ARMv7, RouterOS 7.25.

## Причина и исправление

Официальный sing-box 1.14.4 принял оба профиля, но дал 0/10 успешных запросов
на каждом. В исходном
[reality_client.go](https://github.com/SagerNet/sing-box/blob/v1.14.4/common/tls/reality_client.go)
перед рукопожатием удаляется X25519MLKEM768 из SupportedCurves и KeyShare.
Совместимость с новыми REALITY-серверами также обсуждается в
[upstream issue #4520](https://github.com/SagerNet/sing-box/issues/4520).

Собрана локальная версия `1.14.4-local.mlkem1` с отдельным флагом
`tls.reality.enable_mlkem=true`. Он сохраняет гибридную долю; по умолчанию
поведение upstream остаётся прежним. Для этих двух серверов выбран fingerprint
`chrome`. Серверные параметры доступа и flow не менялись.

Патч, тест и инструкции: `patches/`. Это локальная сборка с `with_utls`,
а не немодифицированный официальный binary и не полный набор его расширений.

## Проверки

Запросы выполнялись одновременно через два loopback-входа; SSL-проверка
конечных сайтов включена. Имена профилей: SV-testARM и FL-testARM.

| Серия | SV | FL |
|---|---:|---:|
| Официальный 1.14.4, исходный randomized | 0/10 | 0/10 |
| Локальный ML-KEM + chrome, быстрая серия только gstatic | 7/10 | 7/10 |
| ML-KEM + chrome, 3 разных сайта, пауза 2 с | 30/30 | 30/30 |
| ML-KEM + chrome, 3 разных сайта, пауза 0.5 с | 18/20 | 20/20 |
| Намеренно неверный public_key | 0/1 | 0/1 |
| Проверка через панель после перезапуска контейнера | успешно | успешно |

Сайты смешанной серии: example.com, Cloudflare trace, Google generate_204.
Через оба профиля в длинной серии загружен файл 95 766 байт с raw.githubusercontent.com.
В ускоренной серии у SV последние два запроса и последующее скачивание дали
тайм-аут; FL прошёл все запросы и скачивание. В первой быстрой серии только
gstatic последние три запроса обоих профилей также дали тайм-аут.
Ошибка `reality verification failed` исправлена, но отсутствие тайм-аутов при
любой интенсивности нагрузки **не подтверждено**; особенно это касается SV.
Причина оставшихся тайм-аутов не установлена.

Go-тест реального ClientHello прошёл для legacy и hybrid режимов.
Неверный public_key по-прежнему отклоняется: проверка подлинности не отключена.
12 тестов импорта и управления компонентами прошли на ARMv7.

## Сохранённое состояние

- Binary: `/usr/local/bin/sing-box`, SHA256
  `c38fa0d889a53e014017f3ecffe3d92410deb3c4d9041cc9edc7f25242560715`.
- Приватный config: `/etc/mihomo/clients/sing-box.json`, каталог 0700, файл 0600.
- Два mixed-входа: `127.0.0.1:18181` (SV) и `127.0.0.1:18182` (FL).
- Sing-box запускается и останавливается вместе с тестовым контейнером.
- Во вкладке VPN добавлены SOCKS5-мосты `SB-SV` и `SB-FL` к этим входам.
  В балансировку они не включены; общие маршруты роутера не переключались.
- Проверка в панели работает и для отключённых в балансировке профилей.
- Компоненты показывают локальную версию; apk-обновление поверх неё запрещено,
  поскольку удалило бы исправление. Обновление — пересборкой с патчем.
- Настройка лимита диска временно отключена в `rules/resource-limits.json`.
- Жёсткий cgroup memory.max сохранён: 199 999 488 байт. Soft GOMEMLIMIT:
  Mihomo 80 МиБ, sing-box 60 МиБ.
- В итоговом замере работают оба процесса, memory.current — 29 523 968 байт;
  max/oom/oom_kill — 0/0/0. Это cgroup-замер в конкретный момент, не профиль
  максимального RSS при длительной нагрузке.
- Du итоговых системных каталогов, ядра, настроек и баз: 130 460 КиБ,
  примерно 133.6 МБ. Получилось меньше размера полного официального binary
  благодаря ограниченному набору сборочных расширений.
- `mihomo-arm32` остаётся остановленным по указанию пользователя.
- RouterOS start-on-boot для тестового контейнера не менялся: проверен
  повторный запуск самого контейнера, не автозапуск после перезагрузки роутера.

Секреты не включены в отчёты и образ. Рабочий приватный config входит в
полную резервную копию панели. Временные исходные копии профилей удалены.
Восстановление проверяет config sing-box и перезагружает локальный клиент.

Обезличенные исходные результаты: `build/engine-tests/sing-box-mlkem-*.json`,
результат проверки панели после перезапуска:
`build/engine-tests/sing-box-panel-after-restart.json`.
