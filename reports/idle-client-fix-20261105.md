# Остановка неиспользуемых клиентов — 2026-11-05

Причина: выбор Mihomo сохранился у обоих соединений, но запуск sing-box зависел от наличия его старого JSON, а удаление проверяло только pidof. Старый процесс продолжал работать без ссылок из текущих соединений.

Исправлено: учёт реальных ссылок на клиент и локальных мостов, остановка неиспользуемого клиента, запрет удаления при наличии зависимых соединений. Для sing-box supervisor остаётся в режиме ожидания без дочернего бинарника, чтобы старый entrypoint не остановил весь контейнер. При выборе sing-box его процесс возобновляется. Исправлена отправка перезагрузки supervisor вместо SIGHUP непосредственно дочернему клиенту.

Проверено: 5 новых тестов жизненного цикла + 8 тестов выбора клиентов. Удаление через очередь панели: действие 45 done. Бинарник /usr/local/bin/sing-box отсутствует, pidof sing-box возвращает 1; оба соединения сохраняют client=mihomo. Задержки после удаления: SB-FL 63 мс, SB-SV 61 мс. Запрос через HTTP-прокси: HTTP 204.

Перед удалением сохранена локальная сборка на NAS в before-idle-client-fix-110203. SHA256 копии и оригинала совпали: c38fa0d889a53e014017f3ecffe3d92410deb3c4d9041cc9edc7f25242560715. Настройки сохранены, на прежний VPN-клиент подключения не возвращались.
