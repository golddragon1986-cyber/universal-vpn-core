# Выбор VPN-клиента для соединения — 2026-11-05

В таблице VPN добавлена отдельная колонка «Клиент»: Mihomo, sing-box, Xray. Выбор применяется отдельной кнопкой через очередь конфигурации. Неустановленные клиенты отключены в списке. При создании соединения также есть выбор клиента.

Параметры исходного соединения сохраняются в managed-proxies.json отдельно от локального моста. Перенос между движками реализован для VLESS, VMess, Trojan, Shadowsocks, HTTP/SOCKS; sing-box дополнительно Hysteria2 и AnyTLS. Поддержаны TCP, WebSocket и gRPC в пределах явно описанных полей. Неизвестные параметры и неподдержанные протоколы отклоняются до замены, без потери параметров. Для остальных протоколов сохраняется непосредственная конфигурация Mihomo. Наличие протокола в самом ядре не означает наличие конвертера панели.

Перед заменой проверяется конфигурация выбранным бинарником, после — доступность соединения через API провайдера USER-MANAGED. При ошибке возвращаются прежний клиент и настройки. При новых sing-box-соединениях используется общий процесс с существующими мостами. Xray запускается отдельным управляемым процессом при наличии конфигурации. Конфигурация Xray включена в резервные копии и журнал восстановления.

Проверки: 8 тестов выбора клиентов и 12 существующих VPN-тестов; синтаксис изменённых Python-модулей. Интеграционно создана отключённая копия текущего подключения, переключена на sing-box, проверена доступность и сохранение endpoint/client/balance; тестовая запись удалена, исходная БД и конфигурация sing-box восстановлены. Применение выбора через браузер — действие 39, done. Повторная проверка SB-FL через Mihomo не прошла, автоматический откат вернул sing-box; после отката задержка 67 мс. Ранний тест имел ошибочный адрес API и не являлся свидетельством несовместимости; исправлен и добавлен регрессионный тест. Xray не установлен, живой тест Xray не проводился.

Итог: оба рабочих подключения остались на sing-box; запрос через HTTP-прокси — HTTP 204. Счётчики трафика сохранились после перезапуска. Резервные копии на NAS: before-vpn-clients-104419 и vpn-client-selection-ready-105357 в каталоге устройства за 2026-11-05, с SHA256.
