# Кнопка обновления локального sing-box

У локального sing-box во вкладке компонентов добавлена кнопка «Обновить»
вместо надписи о пересборке. Работает через существующую очередь действий.

Штатный Alpine apk не подменяет локальную ML-KEM-сборку. Подготовленные
совместимые обновления размещаются администратором в
`/etc/mihomo/updates/sing-box/`: исполняемый файл `sing-box` и `release.json`
с полями `version` и `sha256`. Удалённого каталога совместимых релизов сейчас
нет; кнопка честно сообщает отсутствие новой подготовленной сборки.
Она не проверяет upstream на наличие обычных неподготовленных бинарников.

Перед установкой: SHA256, версия бинарника, проверка текущего приватного
конфига новым executable, место для отката, проверка PID управляющего
supervisor по /proc/cmdline. Новый файл атомарно устанавливается с fsync,
SIGHUP направляется supervisor, который запускает новый binary и выполняет
проверки локальных мостов. Успех определяется по новой generation, версии
и успешным пробам всех мостов. При отказе предыдущий binary возвращается.

Supervisor поддерживает управляемый SIGHUP, не завершая себя и весь
контейнер. При неудачной установке нового клиента остаётся жив, чтобы
панель могла выполнить откат. Обычные сетевые таймауты не вызывают
самостоятельных циклических перезапусков.

Шесть unit-тестов внутри ARMv7: отсутствие подготовленного обновления,
уже установленная сборка, неверный checksum, несовместимый конфиг,
успешная замена и восстановление старого binary при отказе проверки.
Подготовленного нового релиза в текущей установке нет; фактическое
обновление на иной binary в этой задаче не выполнялось.

Живое действие №32 завершилось done с сообщением об отсутствии новых
подготовленных сборок. Управляемый SIGHUP проверен на установленном binary:
PID supervisor сохранился, generation 1 → 2, оба моста 2/2 прошли проверку,
версия осталась 1.14.4-local.mlkem1; весь контейнер при этом не перезапускался.
