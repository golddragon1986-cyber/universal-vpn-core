# Проверка двух VPN через sing-box и Xray на RB4011

Дата: 4 ноября 2026, около 19:48–19:58 МСК.
Среда: RB4011, RouterOS 7.25, ARMv7; контейнер `universal-vpn-core`.
По отдельному подтверждению пользователя рабочий `mihomo-arm32` остановлен.
Его настройки, маршруты и VPN-профили не изменялись.

Из рабочего контейнера скопированы два управляемых VLESS/REALITY-профиля:
первый — `SV-testARM`, второй — `FL-testARM`. Исходный fingerprint — `randomized`,
flow — `xtls-rprx-vision`, в настройках Mihomo включён `support-x25519mlkem768`.
UUID, адреса серверов, SNI и ключи в отчёт не включены.

## Методика

Каждый движок запускался отдельно в тестовом контейнере, с двумя loopback HTTP
входами 18181/18182 и маршрутизацией каждого входа через соответствующий профиль.
Глобальные маршруты, TUN и настройки панели не менялись.
В каждом основном прогоне — 10 раундов параллельных HTTPS-запросов через оба
профиля к `https://www.gstatic.com/generate_204`, тайм-аут 10 секунд.
Успех — проверенный HTTPS-ответ 204. Проверка TLS-сертификатов не отключалась.

Проверены исходный fingerprint и отдельная копия с fingerprint `chrome`.
Остальные параметры серверов и доступа сохранены.

## Результаты

| Движок | Fingerprint | SV-testARM | FL-testARM |
|---|---|---:|---:|
| sing-box 1.13.11, Alpine v3.24 | randomized | 0/10 | 0/10 |
| sing-box 1.13.11, Alpine v3.24 | chrome | 0/10 | 0/10 |
| Xray 26.10.31, официальный ARMv7 binary | randomized | 0/10 | 0/10 |
| Xray 26.10.31 | chrome | 7/10 | 10/10 |
| Xray 26.10.31, короткий повтор | chrome | 1/1 | 1/1 |

Все преобразованные конфигурации успешно прошли проверку соответствующим
движком. У sing-box ошибки соединений — `reality verification failed`.
У Xray с chrome первый профиль дал три тайм-аута подряд в конце основной серии;
второй прошёл все 10 запросов. Это подтверждает работоспособность обоих через
Xray/chrome в данном окне, но не стабильность первого профиля и не длительную
стабильность второго.

Дополнительное скачивание 1 МиБ с `speed.cloudflare.com` не прошло: в основной
серии первый профиль дал тайм-аут, второй — HTTPError; в коротком повторе оба
вернули HTTP 403 Forbidden. Поэтому этот тест не подтверждает передачу файла
и не используется как доказательство отказа VPN-туннеля.

## Контроль и ограничения

Изолированный контрольный Mihomo 1.19.33 с теми же исходными профилями дал
`tls: CurvePreferences includes unsupported curve`. Этот отдельный процесс
запускался без штатного supervisor рабочего контейнера, который умеет повторять
запуск при этой ошибке. Результат не описывает работу штатного рабочего
контейнера и не означает, что его профили перестали работать.

По GitHub API актуальный стабильный sing-box во время проверки — 1.14.4.
Его официальный ARMv7-архив скачан на компьютер, SHA256 проверен:
`fd164ed45ebc784f657a3e1d0e0ad0f68afdcff864ee57122c2cfed3ddb80a00`.
Бинарник занимает 73 662 590 байт. С основой около 99.7 МБ это превысило бы
лимит 150 МБ, поэтому он не устанавливался и не запускался в контейнере.
Выводы об отказе sing-box относятся только к проверенной версии 1.13.11;
результат 1.14.4 неизвестен. Для отдельной проверки потребуется компактная сборка
либо изменение бюджета диска.

Максимальные замеренные значения memory.current всего тестового контейнера:
sing-box — 90 628 096 байт, Xray — 38 461 440 байт.
Счётчики memory.events max/oom/oom_kill после тестов: 0/0/0.
Это дискретные замеры cgroup, а не непрерывный профиль пиков RSS.

Пакет sing-box временно довёл размер до примерно 152.5 МБ; до запуска тестов
удалены сгенерированные Python bytecode-кэши. Во время проверки sing-box
суммарный du системных каталогов, ядра, настроек и баз — около 148.0 МБ.
В сборке и установленном entrypoint отключено создание Python bytecode-кэша.
Клиенты проверялись по очереди; одновременно оба бинарника не сохранялись.

## Итоговое состояние

- `mihomo-arm32` оставлен остановленным по указанию пользователя.
- `universal-vpn-core` работает, основной процесс Mihomo и панель сохранены.
- Диагностические sing-box/Xray-процессы остановлены, пакет sing-box удалён.
- Временные двоичные файлы Xray и копии секретных профилей удалены.
- Обезличенные JSON-результаты сохранены в `build/engine-tests/`.
- Конфигурации проверки не добавлены в пользовательскую базу панели.

Тестовый скрипт: `test-vpn-engines.py`. Бинарник Xray передавался из ранее
загруженного официального диагностического набора; SHA256:
`2a893d5b5f7cf5a33168c102f01771ed69a674abeab0b8fb085b1ddf098cf52c`.
