# Скорость TCP-прокси с роутера и из контейнера

6 ноября 2026, после постоянного включения legacy REDIRECT для LAN TCP.
По новому прямому запросу владельца проведены замеры скорости.

Одинаковые условия: один TCP-поток, SV-inbound через sing-box,
http://speedtest.selectel.ru/100MB, HTTP Range 0–33554431 (ровно 32 МиБ).
Только для тестового домена временно выбирался CHANNEL-SV-inbound.
Постоянные файлы конфигурации не изменялись.

| Источник | Путь | Время | Скорость |
|---|---|---:|---:|
| RouterOS /tool fetch, src=192.168.99.1 | Fake IP → legacy REDIRECT → Mihomo redir-port → sing-box/SV | 19.23 с | 13.96 Мбит/с |
| Python в контейнере | HTTP mixed 127.0.0.1:1080 → sing-box/SV | 16.99 с | 15.80 Мбит/с |

Оба ответа HTTP 206, полный ожидаемый объём. Для контейнера наблюдалась
цепочка HTTP: SV-inbound > CHANNEL-SV-inbound. Данные отбрасывались,
на USB скачиваемый файл не сохранялся. Результаты — одиночные замеры на
данном сервисе при обычном клиентском трафике, не максимальная скорость тарифа.

CPU (100% = одно ядро):

- С роутера: Mihomo 28.5%, sing-box 73.7%; средняя загрузка хоста 64.1%.
- Из контейнера: Mihomo 42.3%, sing-box 87.8%, тестовый Python 17.8%;
  загрузка хоста 69.7%, наиболее занятое ядро 98.1%.
- Память контейнера: пик 126.6/123.8 МиБ.
- Swap ~1.46 МиБ без роста; high/max/oom/oom_kill не увеличились.

В этой серии основная вычислительная нагрузка — sing-box. Разные клиенты
загрузки (RouterOS и Python) вносят разные собственные расходы.

После замеров штатная конфигурация загружена обратно, временное правило
Selectel удалено; постоянный TCP redirect и UDP TUN сохранены.

## Дополнение: четыре параллельных соединения

Тот же SV-inbound/sing-box, четыре отдельные TCP-загрузки по 32 МиБ,
суммарно 128 МиБ. Все четыре ответа HTTP 206, все данные получены.

| Источник | Общее время | Суммарная скорость | Средний CPU хоста |
|---|---:|---:|---:|
| RouterOS, прозрачный TCP | 39.01 с | 27.53 Мбит/с | 85.2% |
| Контейнер, HTTP mixed 1080 | 37.00 с | 29.02 Мбит/с | 94.8% |

Время RouterOS включает запуск четырёх SSH-команд; загрузки перекрывались,
длительности отдельных потоков около 30–38 секунд. Контейнерный тест
выполнялся четырьмя потоками Python, собственная нагрузка измерителя 25.6%
одного ядра. CPU sing-box 148.6% / 170.3% одного ядра соответственно.
В контейнерном тесте каждое ядро было занято примерно на 94–96%.

Swap около 1.88 МиБ без роста, high/max/oom/oom_kill не увеличились.
Ускорение относительно одного соединения примерно 1.8–2.0 раза; здесь
ограничением является вычислительная нагрузка всей системы.
После теста штатная конфигурация восстановлена.
