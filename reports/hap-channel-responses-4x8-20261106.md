# hAP ac³: ответы по каналам, 4 серии по 8

Selectel HTTP /100MB, Range bytes=0-262143 (256 КиБ), curl limit-rate 16k, timeout 25 секунд. Это проверка ответов и завершения небольших загрузок, не измерение пропускной способности. Запросы идут через mixed proxy 192.168.99.1:11080, временное правило тестового домена направлено в LOADBALANCE (SV-inbound и FL, sing-box). Исходные порты curl заданы явно 46000–46031; соответствие каналу определено из API /connections по sourcePort. Данные не включают секретов.

| Серия | SV-inbound: полный ответ | FL: полный ответ | Дополнительно |
|---|---|---|---|
| 1 | 4/4 | 0/4 | FL: все HTTP 206, по 224 913 байт, таймаут |
| 2 | 4/4 | 0/4 | FL: 4 без HTTP-ответа, таймаут |
| 3 | 4/4 | 0/4 | FL: 4 без HTTP-ответа, таймаут |
| 4 | 3/3 привязанных | 4/4 | один HTTP 502, канал не пойман API |

Полный ответ означает HTTP 206, ровно 262 144 байта, curl exit 0. Среди привязанных запросов SV-inbound: 15/15 полных; FL: 4/16 полных, HTTP 206 получен у 8/16, остальные 8 без заголовков до таймаута. Всего 32 запроса: 19 полных, 4 частичных, 8 без ответа, 1 HTTP 502. Запрос 502 завершился раньше снимка; приписывать его каналу по предполагаемому чередованию нельзя.

Наблюдение: FL отвечал нестабильно в пределах этого теста. Место возникновения задержек/ошибки 502 не локализовано. Ограничение скорости передачи задано клиентом; таймаут частичной загрузки не означает полного отсутствия ответа сервера. После четырёх серий постоянная конфигурация восстановлена, панель HTTP 200.
