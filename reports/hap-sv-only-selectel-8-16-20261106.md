# ac³ после отключения FL: 8 и 16 соединений

FL не включался. Временное правило домена Selectel направляло тестовый трафик только через SV-inbound; цепочка каждого активного запроса подтверждена API. Cloudflare сначала вернул HTTP 429 всем запросам; эта попытка исключена из измерения.

Внешний компьютер → mixed proxy 192.168.99.1:11080 → SV-inbound/sing-box → speedtest.selectel.ru/100MB, Range 32 МиБ на поток, лимит 25 секунд. Все 8 и все 16 потоков получили HTTP 206 и данные; остановлены по установленному времени (curl 28). Скорость посчитана по фактическим байтам и общему времени, включая короткие диагностические запросы.

| Потоки | Получено, байт | Время | Скорость суммарно | Средняя CPU по снимкам | Пик CPU |
|---|---:|---:|---:|---:|---:|
| 8 | 75 448 844 | 25,56 с | 23,61 Мбит/с | 90,2% | 98% |
| 16 | 89 837 868 | 27,52 с | 26,11 Мбит/с | 91,7% | 93% |

Рост скорости около 10,6%, CPU близок к насыщению на обеих ступенях. Это текущий результат Selectel, напрямую сравнивать с прошлыми Cloudflare 52/59 Мбит/с нельзя. Временное правило после тестов удалено, постоянная конфигурация восстановлена. Панель HTTP 200.
