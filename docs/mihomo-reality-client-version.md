# Совместимость Mihomo с новыми серверами REALITY

Штатный Mihomo v1.19.34 передаёт в REALITY версию клиента `1.8.2`. Некоторые серверы Xray отклоняют такое соединение. Патч `patches/mihomo-reality-client-version.patch` добавляет необязательное поле `reality-opts.client-version` (три десятичных числа от 0 до 255). Без поля поведение Mihomo не меняется.

`scripts/build-mihomo-reality.ps1` собирает ARM64 ядро из проверенного исходника Mihomo v1.19.34 и официального архива Go 1.26.11. Номер версии ядра остаётся `v1.19.34`; строка сборки содержит метку `uvpnc-reality-version`. Панель распознаёт метку и при импорте VLESS/REALITY для Mihomo добавляет `client-version: 26.11.9`. При переводе узла на sing-box или Xray поле удаляется из локального профиля.

На AX3 для planvpn с включённым гибридным обменом получено 5 из 6 успешных проверок `https://www.gstatic.com/generate_204` в двух последовательных прогонах. Шестой узел также завершался тайм-аутом в отдельном тесте Xray. Проверка подтверждает совместимость этих узлов, но не эквивалентность всех реализаций протоколов Mihomo и Xray.

Перед заменой ядра нужно сохранить `/mihomo` и проверить кандидата командой `-t` на `/etc/mihomo/default_config_candidate.yaml`. Встроенная функция `component_binary.install_binary('mihomo', candidate, 'v1.19.34')` проверяет запуск и откатывает бинарник при сбое. Копия официального ядра AX3 находится в `/etc/mihomo/rules/.mihomo-official-v1.19.34`. Перед возвратом к официальному ядру нужно удалить `client-version` из существующих профилей и пересобрать конфигурацию: штатное ядро не знает это поле. После обновления официального Mihomo патч потребуется проверить и собрать заново на новой версии исходника.
