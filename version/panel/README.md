# Обновление панели

Файл `VERSION` задаёт текущую версию панели. Workflow собирает архив панели, прикрепляет его к релизу Universal VPN Core и сохраняет копию в `version/panel/<версия>/panel.tar.gz`. Манифест `stable.json` указывает на эту копию; отдельные panel-релизы не создаются.

Панель запрашивает `stable.json`, принимает только URL файла из каталога `version/panel` и проверяет размер и SHA-256 до установки.

Архив содержит только файлы приложения из `vendor/panel/panel`; конфигурация контейнера, VPN-данные, ключи и RouterOS в него не попадают. При установке текущие файлы панели копируются в локальную резервную папку. Новые файлы проверяются до записи, а при сбое записи или старта панели восстанавливается прежний код. После успешной фиксации задания перезапускается только веб-панель; VPN-ядро и его конфигурация продолжают работать.

Образ 0.31b принимает только служебный тег `panel-v0.3.1`. После публикации 0.32b манифест укажет на общий релиз. Служебный архив остаётся доступным для старого образа.

Локально собрать архив можно командой:

```sh
python scripts/build-panel-release.py 0.3.2 build/panel.tar.gz
```
