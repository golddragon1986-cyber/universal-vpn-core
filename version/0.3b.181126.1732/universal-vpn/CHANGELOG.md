# 0.3b.181126.1732

Дата: 18.11.2026. Релиз **0.3b** для ARMv7 и ARM64.

- Единый черновик для DNS, основного маршрута, доменов, правил и ручных IP-маршрутов. Рабочая конфигурация меняется кнопкой «Применить конфигурацию».
- Общая отмена; возврат к исходным значениям убирает признак изменений. Черновик сохраняется между вкладками и после перезапуска.
- Действия над VPN, подписками, источниками GeoDAT и компонентами сохраняют немедленное применение.
- Таблица DNS с порядком, названием, адресом, маршрутом, включением и удалением. Последовательное резервирование при ошибке или таймауте; NXDOMAIN завершает запрос.
- Начальные DNS берутся из RouterOS без обратной ссылки на контейнер. При отсутствии служебного DIRECT DNS добавляются 1.1.1.1 и 8.8.8.8.
- Диагностика DNS проверяет серверы по заданным маршрутам, показывает ответ, время, IP/TTL и правило для FakeIP. Запросы IPv4 A; DoH, DoT, TCP и UDP поддерживаются.
- «Основной маршрут» доступен в правилах, IP-маршрутах и DNS и выбран по умолчанию для новых записей. Наследующие записи следуют его переключению; явный маршрут сохраняется.
- Порядок правил: первое включённое совпадение определяет действие, PASS продолжает проверку. Перестановки накапливаются до общего применения.
- Поиск правил по части домена и родительскому суффиксу; список доменов учитывает фактически срабатывающее правило с учётом порядка. Статусы FakeIP, RealIP и NODOMAIN.
- IP-маршруты: поиск сети по входящему IP, метрика, включение/отключение без удаления, пакетное применение. Правила имеют метрику 100; ручная запись может переопределить такую же сеть меньшей метрикой.
- Список доменов загружается по запросу, по 25 строк. Названия правил в доменах и маршрутах открывают соответствующий редактор.
- GeoDAT: поиск по содержимому и названию, число записей, просмотр категории, объединение domain/IP, локальная загрузка и обновление. Крупные списки хранятся отдельными наборами; результаты последнего поиска сохраняются.
- Очистка отменённых файлов GeoDAT-правил, восстановление прерванного применения, защита от применения устаревшего черновика. Все Python/JS-модули новой логики включены в оба образа.

## Начальные данные

Оба образа включают текущие правила RB4011: ru-blocked, telegram, rutracker, nnmstatic и category-ads-all, их порядок и источники GeoDAT. VPN-профили и подписки добавляются после установки.

Полные исходные GeoDAT-базы скачиваются на вкладке GeoDate; в образах сохранены их ссылки и готовые наборы используемых правил. Начальная таблица DNS создаётся по настройкам устанавливаемого RouterOS. Файл `PORTABLE-SETTINGS.json` содержит снимок параметров DNS и ручных IP-маршрутов для переноса; установщик не создаёт из него маршруты конкретного стенда.

## Установка

Скопируйте каталог `universal-vpn` и следуйте `README.md` или `README.html`. Это установочный комплект, не автоматическое обновление работающего контейнера. Перед переустановкой сохраните резервную копию; полное удаление стирает рабочие данные.

## Проверка

Проверены логика наследования, порядок/метрики и откат маршрутов, изоляция/восстановление черновика, резервирование DNS и начальная сборка конфигурации с пустым списком VPN. Файлы образов проходят контроль OCI, архитектуры и SHA256.
