# Обновление панели из GitHub

Пока репозиторий пуст, стабильного манифеста и доступных обновлений нет. Чтобы включить канал обновлений:

1. Загрузить в основную ветку проверенные исходники панели из `vendor/panel/panel`, этот каталог и workflow `.github/workflows/release-panel.yml`.
2. Убедиться, что workflow присутствует в основной ветке.
3. Создать и отправить тег вида `panel-vX.Y.Z`, например `panel-v0.3.1`.

Workflow соберёт `panel.tar.gz`, посчитает SHA-256 архива и каждого файла, опубликует архив как GitHub Release и запишет `updates/panel/stable.json` в основную ветку. Панель запрашивает этот фиксированный манифест, принимает только ожидаемый URL релиза и проверяет размер и SHA-256 до установки.

Архив содержит только файлы приложения из `vendor/panel/panel`; конфигурация контейнера, VPN-данные, ключи и RouterOS в него не попадают. При установке текущие файлы панели копируются в локальную резервную папку. Новые файлы проверяются до записи, а при сбое записи или старта панели восстанавливается прежний код. После успешной фиксации задания перезапускается только веб-панель; VPN-ядро и его конфигурация продолжают работать.

Локально собрать архив можно командой:

```sh
python scripts/build-panel-release.py 0.3.1 build/panel.tar.gz
```
