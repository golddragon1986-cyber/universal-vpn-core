Проверка не устанавливает компоненты.

КомпонентТекущая версияВыбрать и установить версиюУправление

Проверка загружает только каталоги версий для архитектуры контейнера. Установка или переустановка выполняется отдельной кнопкой и сохраняет настройки.

Для Mihomo, sing-box и Xray доступны стабильные сборки из последних 100 публикаций GitHub. OpenVPN и WireGuard tools используют версии из подключённых репозиториев Alpine.

Для установленных системных пакетов проверка показывает версии из репозиториев Alpine. Кнопка «Обновить» применяет обновление пакета и его зависимостей.

Mihomo обслуживает DNS и маршрутизацию, поэтому его нельзя удалить. Перед заменой ядра и VPN-клиентов выбранная сборка проверяется с текущей конфигурацией. Несовместимая сборка не заменяет работающую.
